- `common/` - Reusable UI components (Button, Card, Input, Modal, etc.)
- `flashcard/` - Flashcard-specific components (FlashcardForm, FlashcardCard, CodeSnippet)
- `navigation/` - Navigation components (Sidebar, TopBar)
- `stats/` - Statistics components (StatCard)
